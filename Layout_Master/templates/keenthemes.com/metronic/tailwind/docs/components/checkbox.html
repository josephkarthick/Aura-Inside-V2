Tailwind CSS Checkbox

Tailwind CSS Checkbox is a custom component designed to enable styled form checkbox contorls that offer consistency and ease of customization across various forms.

Metronic integrates the KTUI Checkbox component to deliver a flexible and user-friendly interface for Tailwind CSS Checkbox. For detailed guidance on implementation and customization, refer to the KTUI Checkbox documentation.
